# ZIC Encoder

**One key. Your input. A repeatable result.**

ZIC Encoder is a minimal password-generation application designed to help users generate repeatable passwords using a personal key and custom text input.

The application focuses on simplicity, portability, and user control. It provides a straightforward way to manage a personal key and generate passwords without relying on a conventional online account or cloud-based password service.

## Core Features

- **Password Generation** — Generate repeatable passwords using a personal key and custom input.
- **Key Creation** — Create a new personal key.
- **Key Import** — Restore an existing key when moving between devices.
- **Key Export** — Export a key for backup or transfer.
- **Local-First Approach** — Designed around local use and user-controlled key management.
- **Minimal Interface** — A simple, focused experience without unnecessary complexity.

## How It Works

1. **Create or import a key.** Establish the key used for password generation.
2. **Enter your input.** Provide the text associated with the password you want to generate.
3. **Generate your password.** Use the same key and input to reproduce the corresponding result.
4. **Manage your key.** Export or import your key when necessary.

## Design Philosophy

ZIC Encoder is built around three principles:

- **Simplicity** — Make password generation straightforward.
- **Control** — Keep key management in the user's hands.
- **Consistency** — Make repeatable password generation the central experience.

## Project Goals

ZIC Encoder explores an alternative approach to password generation, reducing dependence on conventional account-based systems while keeping the user experience accessible and focused.

## Security Note

Your key is essential to reproducing generated passwords. Keep it secure and maintain a safe backup. The application's security depends on the design and implementation of its key management and password-generation processes.
